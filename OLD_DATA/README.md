# OLD_DATA

Retired scraping scripts and their intermediate output. Nothing here is part of
the build — the app ships `app/src/main/assets/orot_data.json`, which is now
generated by `app/src/main/scripts/build_orot_data.py` from the Wikisource
export.

**Do not run the scripts in this directory.** They still write to
`app/src/main/assets/orot_data.json` using a path relative to the repo root, so
running one from the repo root overwrites the shipped asset with the old,
broken data.

## Why they were retired

The scrapers split raw wikitext on newlines and treated every line as a
paragraph. Because a wikitext line break is an editing artifact rather than a
structural one, the result was:

- **Duplicated text** in 15 chapters — the vowelled and the unvowelled copy of
  the same page emitted as consecutive "paragraphs".
- **Invented paragraph boundaries** in 97 of 146 chapters.
- **Navigation links and headings as body text** ("לתוכן העניינים", "א. צמאון לאל חי").
- **Missing content** — pages that are redirects yielded only the redirect line,
  so all of "זרעונים: ד. מעשי יצירה" was lost.
- **Fabricated letters** — each fragment was lettered א׳, ב׳, ג׳ by index, even
  though in אורות the letter belongs to the piska, not to a line within it.
